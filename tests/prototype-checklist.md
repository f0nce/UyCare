# Prototype walkthrough checklist

These checks concern the browser prototype only. Production acceptance tests remain Not run.

- Reset restores fictional sample data.
- Create request validates required inputs and positive budget.
- Category suggestion is labelled as a rule-based demonstration and can be overridden.
- Filters and price/rating sorts update visible offers.
- A profile shows portfolio examples and review count with demo labelling.
- A provider can submit an offer for a newly created request.
- Accepting an offer records one selected provider and closes competing choices.
- Chat displays a locally sent message without claiming external delivery.
- Provider starts and marks work ready; customer confirms and reviews once.
- Open-request cancellation and assigned-job cancellation have distinct flows.
- Reload preserves local demo state; reset removes it.
- Layout works at 390 px and 1440 px; labels and keyboard focus remain visible.
