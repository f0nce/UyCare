# Editable architecture diagrams

Open the .drawio files in diagrams.net to edit individual shapes and connectors. The matching .svg files are readable exports. diagram-models.json preserves the geometry and labels used to create both representations.

- system-context: actors, UyCare boundary and external media storage.
- use-cases: customer, provider and moderator participation using UML actors and use-case ellipses.
- components: proposed web/Flutter clients, modular backend and storage.
- job-lifecycle: normal transitions, corrections and cancellation paths.

Diagrams describe the target architecture, not a deployed backend. The browser prototype is a separate local demonstration. Cancellation rules and omitted secondary use cases are specified in docs/06-requirements.md.
