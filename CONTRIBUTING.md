# Contribution and review workflow

Use your own identifiable GitHub account and Git author details. Each meaningful work item requires a real YouTrack issue with owner, expected outcome, acceptance criteria and deadline. UCPLAN references in this initial package are temporary planning IDs, not YouTrack issues.

Create a task branch from the reviewed main baseline, make coherent changes and open a PR. Include the actual task ID, problem/result, verification and limitations. Another team member reviews before merging. Attach the PR/commit link to YouTrack and mark Done only when acceptance criteria are met. Documentation and diagram changes follow the same process.

The generated starting package is preparation material. Students must inspect, correct, understand and progressively extend it. Do not change authorship, backdate commits or invent reviews to represent the package as months of independent work. Record actual contributions and AI assistance according to university rules.

Never commit secrets, participant identities, exact private addresses or consent recordings. Keep public research summaries anonymised and privately traceable.
